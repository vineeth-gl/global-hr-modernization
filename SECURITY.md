# Security Policy

## Supported Versions

This repository is an internal demo / educational sample (currently
`1.0.0-SNAPSHOT`) and is not intended for production use. There is no
ongoing release line, so only the latest code on the default branch is
covered by this policy.

| Version         | Supported          |
| ---------------- | ------------------ |
| 1.0.0-SNAPSHOT (latest, `main`) | :white_check_mark: |
| Older/forked copies | :x:              |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

- Do **not** open a public GitHub issue describing the vulnerability.
- Report it privately, preferably via GitHub's "Report a vulnerability"
  feature (Security Advisories) on this repository, or by contacting a
  repository maintainer directly.
- Include as much detail as possible: steps to reproduce, the affected
  component or file, and the potential impact.

Reports are handled on a best-effort basis, since this is a demo project.
You can expect an initial acknowledgement within a few business days.
There is no guaranteed fix timeline, but accepted reports will be
addressed as time permits and credited where appropriate.
